## Goals

There are easy-to-measure and hard-to-measure goals

* Increasing wealth on paper Vs Increasing my effective control over resources


This is a different dicotomy because with easy-to-measure goals, there is a optimisation problem, you 
can define some function f that -> {goal} (For example, # of shares in a profitable stock, or net-savings)

You cannot to the same with hard-to-measure goals, and only develop proxies. But this is lossy. There is a
lot of trial and error here, and as this kind of thing gets more complex a humans ability to reason about these
gets worse.
